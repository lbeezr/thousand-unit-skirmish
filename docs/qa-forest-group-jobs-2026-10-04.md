## Bounded chosen rule

A newly accepted forest click identifies its public authored four-neighbor
connected forest group. Membership is computed once per activated map and does
not split when trees are cut. Terraced Vale has 3,162 forest cells in ten such
groups; four- and eight-neighbor grouping coincide there. A cell deep inside a
group is an anchor, not a command to cut that hidden or inaccessible tree.

Execution chooses only current-visible live group cells with reachable open
access and a real flow route. Nearest distance wins with a soft two-unit penalty
per other selected/active friendly Worker reservation; deterministic cell ties
and shared-target fallback keep small frontiers usable. Only accepted selected
Workers receive new work. There is no hard exclusive lock or job stealing.

The client picker admits remembered crowns as group anchors; unknown crowns and
last-disclosed depleted crowns remain unpickable. The server can receive any
public authored anchor but must find a current-visible reachable frontier before
accepting. Ordinary Wood nodes, Stone, Food, legacy explicit and inferred Wood
intents retain their prior radius-eight/source-class rules. Forest-group work
never switches into a separate grove or ordinary Wood node.

The existing version-one tagged `sourceKind` union gains `forest-group`, Wood
only, with an exact authored cell-center anchor. Checkpoint schema29 already
carries this union and the existing target; no new phase or top-level field is
added. Validation checks generation, anchor, source class and target-group
membership before mutation. Restore derives membership from the original map,
including when the anchor has been cut. Old records remain old area jobs.

After delivery, the existing remembered execution target is a return destination
without a hidden-stock query. Only sight plus arrival permits successor search.
When no current-visible reachable work remains, feedback says
`FOREST WORK ENDED · NO REACHABLE VISIBLE TREES`; it makes no hidden exhaustion
claim. Remaining cargo returns once through source-free delivery, preventing
legacy intent resurrection or an empty retry loop. Stop/accepted Move/manual
replacement continue to take precedence.
