# Runtime environment view coverage — 1 October 2026

The report reads the renderer's actual regional harvest-pack list, then each
loaded atlas's clips. All 18 currently loaded regional harvest atlases have one
intact view; their four resource states do not supply rotated perspectives.
Runtime atlas bytes match declared SHA-256 hashes. This is asset-contract evidence,
not a browser match or anatomical verification of every drawing.

The three generic oak/pine/berry model packs declare eight unique capture hashes
and measured model headings under a fixed camera. They cover intact generic
families, not the regional species or all harvest states. The current podvine
pack has four authored painted views with a verified runtime atlas hash. Its
requested headings are not measured model rotations.

Scope excludes other static scenery, buildings, units and archived candidates.
Do not interpret this report as complete coverage of every environment sprite.
The rejected Root Oak redraw pair and approximate construction guide remain
outside accepted runtime viewpoint counts. The concrete next canopy work is
consistent multi-view construction for Underbough's four forms, followed by
harvest-state coverage and runtime view selection.

Reproduce: `node scripts/report-environment-directions.mjs <output.json>`.

no longer match their declarations; update its parser explicitly in that case.
