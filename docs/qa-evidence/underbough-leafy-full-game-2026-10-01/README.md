# Fuller hornbeam full-game review · 1 October 2026

`RTS_QA_LEAFY_CANOPY=1` runs the reusable local browser QA comparison. Eight
screenshots cover Rootways and Bellweather at ordinary/strategic cameras.
The same authored maps, ground kit and placement compare original hornbeam
with the fuller lifecycle atlas; age factors are not enabled. Fog is disabled
only in disposable map copies.

[Capture report](capture-report.json) has no reported errors.
[Renderer proof](renderer-proof.json) checks candidate family selection,
regional ground textures, cache isolation and unchanged map definition using
separate proof meshes. Prior isolated renderer evidence supplies stock/reset
checks; this does not claim private live-slot inspection, worker harvesting
or hosted validation.

[Original ordinary](underbough-rootways-original-ordinary.png),
[fuller ordinary](underbough-rootways-leafy-ordinary.png) and
[fuller strategic](underbough-rootways-leafy-strategic.png) were inspected.
The fuller tree replaces much of the brown branch lattice with green leaf
mass, but continuous forest strips and repeated crown highlights remain
conspicuous. The study stays opt-in. Next composition work needs distinct
canopy silhouettes and clearer forest edges without obscuring blocked-cell
readability. This is local appearance evidence, not completed map beauty.
