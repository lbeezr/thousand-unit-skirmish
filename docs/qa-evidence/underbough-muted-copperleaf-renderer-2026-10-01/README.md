# Muted copperleaf renderer preview — 1 October 2026

`forestCopperleaf=muted` swaps only Underbough copperleaf presentation to the
four-state muted atlas. Default art remains original. Public atlas metadata and
runtime frames are allowed by the server; individual-frame fallback is included.

Actual renderer captures use Rootways, fixed camera and plain background. Both
modes retain 1,026 wood owners and the same species counts; all 51 copperleaf
slots switch to the candidate family. Candidate stock 6/3/1/0/6 has expected
atlas rectangles and finite transforms, loaded textures and unchanged source
map. Reset capture is pixel-identical. JavaScript syntax checks pass.

Inspected original and muted full-stock images show quieter warm canopy accents.
Repeated hornbeam anatomy, root clutter and prominent understory colors remain.
This isolated view does not establish full-game palette acceptance, live worker
harvesting or hosted behavior. No new rotated perspectives are added.
