This is a curated starting shelf for creative work across the client, lobby,
modes, battlefield and character voices. Fifteen visually inspected preserved
references each have a particular use, a status, a limitation and a link back
to their existing source/provenance. Filter by subject/status or search a detail.
Click an image to inspect its original. All sources remain visible when script
is disabled; images, styles and controls need no external host.

The editable HTML is a standalone documentation entry: open it from this checkout,
or serve the repository with a documentation-only static server. Keep its relative
directory structure. Linked Markdown is read in the repository/editor rather
than converted into an additional wiki. No game server, install, build, paid
generation or new public route is required. These HTML/SVG sources are outside
production admission and do not ship as game UI.

## Selection and provenance

[Source receipt](sources.json) records the baseline, exact original paths, SHA-256
hashes, byte counts, status, selection reasons and limits. These are hashes
observed during this curation, not a new asset approval or a replacement for
pack manifests. Original rights and publication scope remain in the linked source
records. Private manuscripts stay private; the source study describes them,
and missing original prose remains missing. No third-party artwork is imported.

Selected reference means the underlying regional/identity/composition direction
was selected in its existing record. Working source means usable architecture
development. Exploratory means useful comparison with no new selection. Historical
capture means evidence for its dated build and scope only. The HUD card uses an
**exploratory generated backdrop**; the linked 72px Obsidian treatment has its own
user selection in the component record. This avoids relabeling the entire study
as approved because one component was chosen.

The new SVG is a code-authored six-stage composition/state study backed by the
linked art and guides. It uses schematic shapes, not edited source images.
The path from welcome to planning to command reduces ornament as attention
rises. It proposes no new screens, cinematic delay, map geometry, fictional
seat identity or event meaning. Product text and spoken samples in it are
calibration material; authoritative runtime state controls any future adoption.

Two external primary text references were read 14 October: Riot's
[Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)
(12 March 2021) supports silhouette, hierarchy and restraint; its
[Hextech UI article](https://www.riotgames.com/en/news/under-hood-league-client%E2%80%99s-hextech-ui)
(14 February 2017) supports shared interface foundations. Application to Vaelora
is our design interpretation. No assets or text passages are reproduced.
The existing Blizzard starting-page reference returned no readable content in
this check; earlier research stays dated rather than becoming a fresh-site claim.
