# Bellweather Sheep reference study v1

**2 October 2026:** newly generated host-native ImageGen source candidate.
One sheet, one invocation, using the tracked Bellweather ecology key. No Meshy,
paid external provider, private manuscript input or runtime change.

![New Sheep concept reference sheet](bellweather-sheep-reference-v1.png)

The sheet gives four anatomy views and four oblique studies of the cream-fleeced
sheep. It is preserved as a concept candidate, including the defects. The lower
row's yaw labels are **not accepted game registration**: the bottom-left sheep
does not face along the drawn +Z axis. Dimensions, axes and root marks are
illustrative, not mechanical measurements. See [pixel review](review.json).

The design targets remain fixed: orthographic camera 45° azimuth /
45.4359024848° elevation, +Y up, yaw zero +Z; proposed shoulder height 0.60 world
units, nose-to-rump 0.90, root at the planted hoof-plane center. Target anatomy is
four legs, cream overlapping wool locks, pale sheep face, lateral brown-pink
ears, bare lower legs and dark cloven hooves; no horns or harness. These targets
do not turn hand-drawn labels into validated geometry.

This opaque sheet has baked labels, guides and shadows; it is not a transparent
sprite atlas. No eight-heading registration, gait, carcass/resource states,
engine loader or human acceptance has been delivered. The next bounded art
outcome is a corrected direction study using a deterministic camera guide.
