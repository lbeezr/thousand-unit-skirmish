# Bellweather Sheep reference study v2

**2 October 2026:** preserved intermediate annotation edit, superseded by the
[approximate-angle v3 sheet](../bellweather-sheep-reference-v3/README.md).

![Sheep descriptive-view correction v2](bellweather-sheep-reference-v2.png)

One built-in ImageGen edit of [v1](../bellweather-sheep-reference-v1/README.md)
removed its misleading world-axis arrows, numerical measurement bars and pivot
crosses. The eight drawings retain the Sheep's appearance and planted poses in
pixel review. Descriptive front/side/back labels replaced the rejected yaw labels;
the footer explicitly calls the proposed dimensions unmeasured. This revision
predates the request that all applicable design references carry degree labels.

This is an opaque concept sheet with baked labels and shadows. It does not
establish identical geometry across views, runtime camera projection or registered
sprites. [v3](../bellweather-sheep-reference-v3/README.md) adds clearly approximate
degree labels under the verified runtime convention while retaining this attempt.
