# Registered public Archer coverage

48 complete poses reused from the retained public [Archer v1 sheet](../archer-sprite-v1/README.md): eight idle views, sixteen walk keys, sixteen bow-draw/release keys and eight terminal poses. **Zero newly authored, generated, mirrored or interpolated poses.** [Review](review.png) shows every actual key; [registration](registration.json) identifies source boxes, translations and the original public hash.

The old floor-divided atlas severely cut feet at row borders. The shared [registration script](../../../scripts/register-legacy-foot-sprites.py) recovers complete connected actors before translation and excludes neighbouring-row pixels. It keeps source pixels at scale 1, the original blue-sash mask, the fixed (160,308) pivot, crop offsets and four-pixel padding. The shared 1.2161865 world-unit body baseline is calibrated to the source's 175-pixel standing body. Isolated sub-threshold source noise outside two pixels of an actor is omitted. Original v1/v2/source iterations remain intact.

Eight distinct original paintings follow world headings N/NE/E/SE/S/SW/W/NW using physical source columns **5/4/3/2/1/0/7/6**, matching the fixed +X/+Z camera convention. Their drawn angles remain approximate, not certified model rotations. The coherent retained hooded green costume replaces v2's current-role costume throughout this pack, avoiding costume switches between headings/actions. This is a directional function tradeoff, not a finish upgrade.

Two walk keys loop over 800 ms; two draw/release keys play once over the existing Archer 1,000 ms attack lifetime. Defeat holds the real directional idle for 120 ms, then its terminal pose for 730 ms and clamps. The bow/string poses are rough and do not synthesize projectile or damage timing. There are no intermediate collapse keys. No simulation, stance, state-selection, action enum or Worker semantics change.
