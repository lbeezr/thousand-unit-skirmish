# Infantry reference brief

This is a compact design brief for the selected image, not a verbatim record of the original image-generation prompt.

Create one full-body, front-view Infantry character for a painterly low-fantasy RTS. Use a steel-grey rounded cap, a warm umber quilted tunic, dark trousers and boots, simple leather bracers, a long upright wooden spear with a steel point, and a dark six-sided shield with a neutral metal rim. Tie one sky-blue sash at the waist as the only team-color surface. Keep the character centered and isolated on a plain light-grey studio background, with clear separation between body, shield, and spear. No text, extra characters, scenery, or team-colored armor.

The selected input image is the canonical visual target for the first Meshy attempt. The brief is supplementary; Meshy's Image-to-3D API takes the reference image and generation settings, so this text is not represented as an API prompt field.
