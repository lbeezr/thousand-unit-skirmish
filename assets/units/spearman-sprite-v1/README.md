# Human Spearman partial animation pack

Pack 0.7.0 preserves all 44 existing registered poses and adds four locally authored South walk keys from the already-public painted South seed. SE/NE/East/North walks, SE attack/defeat and all eight idle facings remain unchanged. South uses four 200ms contact/passing keys, one 800ms loop, existing body calibration and padded original pivot. Three walk headings, seven attack and seven defeat headings remain missing (17 cells).

The page and zero team mask extend downward from 2048x2048 to 2048x3200; the entire previous page RGBA and grayscale mask pixels remain exact. Existing frame rectangles and calibration stay fixed; normalized UVs use the new page dimensions. Encoded PNG/hash/storage and decoded texture memory increase. This leaves reserved transparent slots for Southwest/West/Northwest without moving any old registration. No matching 3D master, provider job, held v2 art or state/simulation change is involved.

Selected sources and provenance: `docs/art-direction/human-roster-v1/extracted/spearman/walk/south-local-v1/registration.json`. The full `scripts/build-human-spearman-preview.py` builder replays baseline, NE, East, North and South stages; individual older append scripts intentionally guard their reviewed construction stage. Packed original source textures/UVs are exact; CPU sampling changes rendered seed RGBA, while the upper rendering is frozen between new keys. Independent review and integration evidence are retained in the owning South guide. Ordinary GPU gait, support-foot speed, normal/strategic/crowded appearance and deployed acceptance remain pending. All private process and art iterations remain retained.
