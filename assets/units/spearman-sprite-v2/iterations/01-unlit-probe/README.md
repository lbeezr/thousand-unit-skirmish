# Rejected initial public-model probe

Twelve newly rendered SE views of twelve locally authored rigid poses, using only the public humanoid/spear GLB. Rejected because imported COLOR_0 is white (the existing project palette is COLOR_1), and the recorded root was projected before updating the camera matrix. Current capture corrects both. No paid provider, private source or source-file mutation. These frames are not served, packaged or counted as accepted coverage.

Original pixels and the probe receipt are preserved in [rejected-capture.zip](rejected-capture.zip), with [snapshot-hashes.json](snapshot-hashes.json) recording each extracted file's SHA-256. [review.png](review.png) remains directly viewable.
