# Public-model Spearman directional bake

Eight real headings, each with one idle, four articulated walk keys, three spear wind-up/thrust/recovery keys and four backward-fall keys. **96 newly rendered frames from 12 locally authored rigid poses; zero reused sprite frames, paid provider jobs or generation/rigging charges.** The geometry and neutral palette come from the already-public [Frontier humanoid GLB](../../units-buildings/frontier-glb-sample-v2/README.md); the shield/Worker/Archer gear is omitted, while the spear, helmet and team sash remain. No original GLB/Blender source was changed and no private source was read/published.

The only older Spearman sprite pack had SE actions. The public Meshy Infantry bake lacks military equipment; copying Infantry's shield costume into Spearman would hide role identity. This local rigid model is a coarse functional alternative, with deliberately blocky anatomy and limited texture detail. It changes the current painterly costume; it is not a claim of approved visual finish.

[Capture and hashes](capture.json) identify source bytes, actual camera/yaws, limb vertex sets, all 96 PNGs and the editable derived scene. [Review](review.png) displays every key. [Bake script](../../../scripts/bake-public-spearman.py) separates actual left/right leg and arm components for the stride, moves the spear independently of its shared helmet bin for attack, and falls the complete body backward. It uses Blender 4.3.2 Cycles CPU, four threads, eight samples and no denoising. The original palette is COLOR_1; COLOR_0 is white. All camera rotations are real +Y world headings, never mirrored/relabelled pixels.

One shared 2.8 orthographic envelope contains every action/heading; the fixed `[0.78,1.12,0.78]` game camera projects origin to approximately `(128,153.663)`. The canonical capture contains its exact value. Canvas-local pivots and crop offsets retain that root. Geometrically projected feet can extend below the image pivot; the existing `spriteGroundDepthBias` keeps the lowest opaque pixel above terrain without moving it on screen. One world/pixel scale matches the existing 1.2161865 Human body baseline; keys are not individually resized. Ground, source/root and actual game-scale appearance still need ordinary-game verification.

Walk loops at 800 ms; attack plays once at the existing Spearman 880 ms; defeat clamps at its existing 1,080 ms, then the existing fade applies. Every heading has the same lifetime. No damage, order, combat, stance, Worker work, enum or animation selector changes. Normal Human Spearman selects v2 with explicit server/Docker admission of exactly manifest/runtime/mask. Raw frames, scene, script and reviews stay outside HTTP/release admission.

Rebuild with `blender -b --threads 4 --python scripts/bake-public-spearman.py`, then `python3 scripts/package-public-spearman.py`; these write only this derived pack. Original sources and rejected iterations remain: [white/root probe](iterations/01-unlit-probe/README.md), [clipped narrow envelope](iterations/02-narrow-camera/README.md). Author review, integration, containing deployment and native game acceptance remain owned in the [foot-unit workstream](../../../docs/human-foot-unit-coverage.md).
