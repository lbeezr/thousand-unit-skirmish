# Frontier environment concepts v2

**Status:** original generated design studies. The single-cliff model/capture
[pilot](../frontier-cliff-pilot-v1/README.md) is complete; wider kit production is future work.

## Sources and direction

- `art-direction.png`: landscape and six asset studies; a review board, not a model input.
- `cliff-straight-reference.png`: isolated cliff input; the output is transparent
  despite the prompt asking for white.
- `prompts.json`: exact illustration prompts.
- `meshy-request.json`: planning metadata, not a raw API request.

Use fractured stone, mossy olive caps, ochre soil, and distinct oak/pine silhouettes.
Keep open ground quiet. Ground paint remains a world texture; dimensional obstacles
can use model captures. Walkable elevation is a separate gameplay rule.

## Pilot and next steps

The standalone cliff consumed 30 credits under its recorded cap, with no paid
remesh/reruns. It produced eight color/depth views and a review page. Inspect the
[pilot findings](../frontier-cliff-pilot-v1/README.md#findings-and-limits) before
extending the kit: the model is lower than intended and repeated joins need work.

A future corner/end/outcrop/tree family needs separate references, matched capture
registration, repeated-piece review, unit-front/behind occlusion checks, and game-zoom
comparison. Normal battlefield art has not adopted this pilot.

Images were generated on 26 September 2026 without third-party source art. Keep
the original files and provenance; no new license or exclusivity claim is made.
