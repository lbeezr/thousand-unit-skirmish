# Worker HUD typography

The approved Obsidian pilot uses self-hosted DM Sans for labels/numbers and
Barlow Condensed Medium for entity names. No runtime Google Fonts requests.

Unmodified font binaries come from the official
[Google Fonts repository](https://github.com/google/fonts/tree/bd8f81ddb5c74d5c8897b36ad88b440266245103/ofl).
[Provenance](provenance.json) records the immutable revision, source URLs, byte
counts and SHA-256 hashes. DM Sans is a variable font (weight/optical size); only
one static Barlow weight is needed. Arial and Arial Narrow/sans-serif are fallbacks.

- [DM Sans SIL Open Font License 1.1](dm-sans-OFL.txt), copyright the DM Sans Project Authors.
- [Barlow Condensed SIL Open Font License 1.1](barlow-condensed-OFL.txt), copyright the Barlow Project Authors.

These binaries and both licenses ship in the ordinary release and have exact
HTTP admission. This README and source provenance are retained in source.
